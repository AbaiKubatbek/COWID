🚀 БЫСТРЫЙ СТАРТ
================================================================================

ВСЕ В 1 КОМАНДУ (с Docker):
  cd CowID
  docker-compose up
  Откройте: http://localhost:3000

ИЛИ ЛОКАЛЬНО:
  Backend:
    cd backend
    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    python -m uvicorn app.main:app --reload

  Frontend (новый Terminal):
    cd frontend
    npm install
    npm run dev

Затем:
  ✅ Откройте http://localhost:3000
  ✅ Перейдите в Admin панель
  ✅ Добавьте новую корову
  ✅ Распознайте её по фото!

================================================================================
🐛 TROUBLESHOOTING
================================================================================

Backend не запускается:
  → Проверьте Python версию (3.9+)
  → Переустановите зависимости
  → Проверьте что порт 8000 свободен

Frontend не запускается:
  → Проверьте Node версию (16+)
  → npm cache clean --force
  → npm install

Database ошибка:
  → Для SQLite удалите cows.db
  → Для PostgreSQL проверьте подключение

GPU не работает:
  → Проверьте CUDA установку
  → Система автоматически переключится на CPU

Больше помощи:
  → Смотрите INSTALL.md раздел Troubleshooting
  → Проверьте логи Backend'а
  → Откройте Developer Console в browser'е (F12)

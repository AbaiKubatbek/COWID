### 6. ✅ Алгоритм распознавания (КРИТИЧНО - ИСПРАВЛЕНО!)

**ПРОБЛЕМА** (была):
- Threshold 0.6 слишком высокий
- Одна корова путалась с похожей
- Нет гарантии уникальности

**РЕШЕНИЕ** (реализовано):
- **Новый алгоритм с 2-уровневой проверкой**:
  1. Ищем ТОП-1 и ТОП-2 по similarity
  2. Проверяем условие 1: `top1_similarity >= 0.55`
  3. Проверяем условие 2: `(top1 - top2) >= 0.10`
  4. Оба условия → Это наша корова!
  5. Иначе → Не распознана

- **Параметры**:
  - `SIMILARITY_THRESHOLD_STRICT = 0.55` (очень похожа)
  - `SIMILARITY_THRESHOLD_LOOSE = 0.40` (немного похожа)
  - `MIN_SECOND_PLACE_GAP = 0.10` (разница для уверенности)

- **Преимущества**:
  - ✓ Одна и та же корова → всегда распознаётся
  - ✓ Разные коровы → НЕ путаются
  - ✓ Гарантированная уникальность
  - ✓ Debug информация в логах

- **Файл**: `backend/app/ml_models/face_recognizer.py`

## 🚀 Как использовать

### Локально

```bash
# Backend
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# Frontend (в другом терминале)
cd frontend
npm install
npm run dev

# Открываем http://localhost:5173
```

# 📱 ГАЙД ТЕСТИРОВАНИЯ КАМЕРЫ НА МОБИЛЬНОМ

## 📋 Требуемое оборудование

- ✓ Смартфон (iOS 12+ или Android 5+)
- ✓ Wi-Fi или мобильный интернет
- ✓ Браузер (Chrome, Safari, Firefox)
- ✓ Компьютер для деплоя (опционально для локального тестирования)

---

## 🚀 СПОСОБ 1: Тестирование на production (Vercel)

### Шаг 1: Деплой на Vercel (если еще не сделал)

```bash
cd C:\Users\user\Desktop\CowID\frontend
npm run build
vercel --prod
```

**Результат:** https://cowid-frontend.vercel.app

### Шаг 2: Открыть на мобильном

1. На смартфоне открыть браузер (Chrome/Safari)
2. Перейти по ссылке:
   ```
   https://cowid-frontend.vercel.app
   ```

3. ✓ Ссылка должна быть **HTTPS** (с замочком 🔒)
4. ❌ Если `http://` → не будет работать камера!

### Шаг 3: Проверить камеру

1. Нажать кнопку **"📷 Открыть камеру"** (или "Camera")

2. Браузер спросит разрешение:
   ```
   "CowID" хочет получить доступ к камере
   ```

3. Нажать **"Разрешить"** (Allow)

4. ✅ Если видно видеопоток:
   - Включена камера задняя или передняя
   - Можно двигать телефон и видеть изменения
   - Нажать "Снять фото" → должно захватить

5. ❌ Если не работает → смотри раздел "Troubleshooting"

### Шаг 4: Протестировать распознавание

1. Снять фото коровы через камеру (или загрузить готовое)
2. Нажать "Распознать"
3. Система должна показать результат

## 🏠 СПОСОБ 2: Локальное тестирование (на компьютере через мобильный)

### Для Chrome DevTools

```bash
# 1. Запустить dev сервер
cd C:\Users\user\Desktop\CowID\frontend
npm run dev

# Результат: http://localhost:5173
```

### На мобильном:

1. Узнать IP компьютера (в Windows):
   ```bash
   ipconfig
   # Искать "IPv4 Address": 192.168.x.x
   ```

2. На мобильном в браузере:
   ```
   http://192.168.x.x:5173
   ```

3. **⚠️ ПРОБЛЕМА:** камера НЕ будет работать на http://!

### Решение: Использовать ngrok для HTTPS

```bash
# 1. Установить ngrok
npm install -g ngrok

# 2. Запустить dev сервер
cd frontend
npm run dev

# 3. В другом терминале - создать HTTPS tunnel
ngrok http 5173

# Результат: https://xxxx-yy-zzz.ngrok.io
```

4. На мобильном открыть:
   ```
   https://xxxx-yy-zzz.ngrok.io
   ```

5. ✅ Теперь камера должна работать!

## ❌ TROUBLESHOOTING

### 1️⃣ "Камера не работает" / "Черный экран"

**Проверить:**

✓ Открыл через HTTPS?
```
https://cowid-frontend.vercel.app ✓
http://localhost:5173 ✗
```

✓ Дал разрешение браузеру?
```
iOS Safari: Settings → Safari → Camera → Allow
Android Chrome: Settings → Apps → Camera Permissions
```

✓ Другое приложение не использует камеру?
```
Закрыть: WhatsApp, Zoom, другие видео-приложения
```

✓ Браузер поддерживает getUserMedia?
```
Chrome ✓
Safari ✓ (iOS 12.2+)
Firefox ✓
Edge ✓
Opera ✓
```

### 2️⃣ "NotAllowedError" / "Permission denied"

```
Причина: Браузер запросил разрешение, но ты отказал

Решение:
- iOS: Settings → Safari → Camera → Allow для cowid-frontend.vercel.app
- Android: Settings → Apps → Chrome → Permissions → Camera
```

### 3️⃣ "NotFoundError" / "Camera not found"

```
Причина: Нет камеры на устройстве (редко)

Проверить:
- Есть ли физическая камера на телефоне
- Не сломана ли камера
- Работает ли в другом приложении
```

### 4️⃣ "SecurityError" / "HTTPS required"

```
Причина: Доступ к камере требует HTTPS

Решение:
- Использовать Vercel (автоматически HTTPS)
- Или ngrok для локального тестирования
- Localhost (http://localhost) работает ТОЛЬКО на desktop браузере
```

### 5️⃣ "iOS: Camera не работает в Safari"

```
Причина: iOS требует iOS 12.2+ и Safari 12.2+

Проверить:
- iPhone/iPad обновить до последней iOS
- Safari обновить из App Store
- Включить камеру в Settings → Safari
```

### 6️⃣ Медленная загрузка камеры

```
Причина: Плохой интернет или тяжелый браузер

Решение:
- Подключиться к быстрому Wi-Fi
- Закрыть другие вкладки
- Перезагрузить браузер (F5)
- Очистить кэш браузера
```

## 📊 ИНФОРМАЦИЯ ДЛЯ ОТЛАДКИ

Чтобы узнать какой браузер и какие возможности:

```javascript
// Открыть Console (F12) и выполнить:

// Проверка камеры
console.log(
  'HTTPS?', window.location.protocol === 'https:',
  'Camera API?', !!navigator.mediaDevices?.getUserMedia
)

// iOS или Android?
const ua = navigator.userAgent
console.log(
  'iOS:', /iPad|iPhone|iPod/.test(ua),
  'Android:', /Android/.test(ua)
)
```
